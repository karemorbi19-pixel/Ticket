# 🚀 دليل النشر السريع

## خطوات الرفع على الاستضافة المجانية

### 1. GitHub Pages (الأفضل والأسهل)

```bash
# 1. إنشاء حساب جديد على GitHub
# 2. إنشاء repository جديد باسم موقعك
# 3. رفع جميع الملفات إلى الـ repository
# 4. الذهاب إلى Settings > Pages
# 5. اختيار Source: Deploy from a branch
# 6. اختيار main branch ومجلد /root
# 7. حفظ الإعدادات والانتظار 5 دقائق
```

### 2. Netlify (سحب وإفلات)

1. اذهب إلى [netlify.com](https://netlify.com)
2. اسحب مجلد الموقع وأفله في الصفحة
3. انتظر بضع دقائق
4. الموقع جاهز!

### 3. Vercel (تلقائي)

1. اذهب إلى [vercel.com](https://vercel.com)
2. ربط حساب GitHub
3. استيراد الـ repository
4. نشر تلقائي

### 4. InfinityFree (FTP تقليدي)

1. إنشاء حساب على [infinityfree.net](https://infinityfree.net)
2. رفع الملفات عبر FTP
3. الموقع يعمل مباشرة

## 📋 قائمة الملفات المطلوبة للرفع

```
✅ index.html          (الصفحة الرئيسية)
✅ .htaccess          (إعدادات الخادم)
✅ README.md          (دليل الاستخدام)
✅ DEPLOY.md          (هذا الملف)
✅ auth/              (مجلد المصادقة)
✅ store/             (مجلد المتجر)
✅ css2               (ملفات CSS)
✅ cdn-cgi/           (سكريبتات)
```

## ⚠️ ملاحظات هامة

- **لا تقم بحذف أي ملف** - جميع الملفات ضرورية
- **لا تغير أسماء المجلدات** - قد يؤدي إلى كسر الروابط
- **احتفظ بالبنية الأصلية** للمجلدات والملفات

## 🔧 بعد الرفع

1. **اختبار الموقع** - افتح الرابط وتأكد من العمل
2. **اختبار تسجيل الدخول** - جرب Discord/Google login
3. **اختبار اللغة العربية** - تأكد من RTL correctly
4. **اختبار الموبايل** - افتح الموقع من هاتف

## 🆘 المشاكل الشائعة والحلول

### المشكلة: الصفحة لا تعمل
**الحل:** تأكد من رفع جميع الملفات والمجلدات

### المشكلة: CSS لا يعمل
**الحل:** تأكد من رفع ملف css2 والمجلدات الفرعية

### المشكلة: تسجيل الدخول لا يعمل
**الحل:** يحتاج إلى إعدادات Discord/Google API keys

### المشكلة: اللغة العربية غير صحيحة
**الحل:** تأكد من أن المتصفح يدعم RTL
