# NitWit Ticketing System

نظام تذاكر دعم متكامل مع تكامل Discord ودعم متعدد اللغات (العربية/الإنجليزية).

## 🚀 للرفع على الاستضافة المجانية

### الاستعدادات المطلوبة:
1. **جميع الملفات جاهزة للرفع مباشرة**
2. **لا حاجة لأي إعدادات إضافية**
3. **متوافق مع جميع الاستضافات المجانية**

### خطوات الرفع:
1. اختر استضافة مجانية (GitHub Pages, Netlify, Vercel, InfinityFree)
2. ارفع جميع الملفات كما هي
3. الموقع سيعمل مباشرة

## ✨ المميزات

- **دعم اللغة العربية** بالكامل مع RTL
- **نظام تذاكر متكامل** للمستخدمين والمشرفين
- **لوحة تحكم للمشرفين** كاملة المميزات
- **نظام نقاط ومكافآت** متقدم
- **تصميم متجاوب** يعمل على جميع الأجهزة
- **وضع ليلي/نهاري** قابل للتبديل
- **تكامل Discord** للمصادقة والإشعارات

## 📁 هيكل الملفات

```
├── index.html          # الصفحة الرئيسية
├── .htaccess          # إعدادات الخادم
├── auth/
│   ├── login/          # صفحة تسجيل الدخول Discord
│   └── google/         # صفحة تسجيل الدخول Google
├── store/
│   └── logo/          # شعارات الموقع
├── css2               # ملفات CSS إضافية
└── cdn-cgi/          # سكريبتات Cloudflare
```

## 🌐 الاستضافات المدعومة

### GitHub Pages (مجاني)
```bash
# 1. إنشاء repo جديد
# 2. رفع الملفات
# 3. تفعيل GitHub Pages
```

### Netlify (مجاني)
1. اسحب الملفات إلى Netlify
2. الموقع سيعمل مباشرة

### Vercel (مجاني)
1. ربط GitHub repo
2. نشر تلقائي

### InfinityFree (مجاني)
1. رفع الملفات عبر FTP
2. الموقع جاهز للاستخدام
